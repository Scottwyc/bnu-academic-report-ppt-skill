# 代表性论文分析页模板

> 每篇论文固定输出 Why / How / Evidence / Limitation / NOTE。

- **Why**：研究动机与科学问题。
- **How**：数据、网络构建、模型和评价。
- **Evidence**：发表时间、期刊、DOI、下载状态、关键结果。
- **Limitation**：外推边界、数据偏差、可复现性。
- **NOTE**：对当前课题的可借鉴点。
